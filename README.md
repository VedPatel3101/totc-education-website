# TОTC Education Website 🎓

TОTC is a modern education platform website designed to provide students and teachers with a simple and engaging online learning experience.

## ✨ Features

* 🏠 Modern landing page
* 📚 Courses and learning resources
* 📝 Assessments and learning activities
* ⭐ User reviews and testimonials
* 📰 Latest news and resources
* 👨‍🏫 Student and teacher focused sections
* 📱 Responsive design
* 🎨 Clean and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* React.js
* Vite

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project folder:

```bash
cd totc-education-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided in the terminal.

## 🎯 Project Purpose

This project was developed to practice frontend development and create a modern educational platform interface with responsive layouts, learning resources, assessments, testimonials, and news sections.
